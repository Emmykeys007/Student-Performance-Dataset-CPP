# Student Performance Dataset Using C++

## Project Overview
This project is a Computer Science assignment developed using C++ for the course **Data Mining, Data Warehousing and Security**.

The project demonstrates how to create, organize, display and store a fictional student dataset using C++ programming.

## Project Objectives
- Create a fictional dataset containing 10 students.
- Organize student information using C++ structures and arrays.
- Display student records in a formatted table.
- Export the dataset into a CSV file.
- Provide data suitable for basic academic performance analysis.

## Dataset Description

The dataset contains five attributes:

| Attribute | Description |
|---|---|
| Student ID | Unique identification number for each student |
| Department | Student's academic department |
| Level | Student's current academic level |
| Attendance Percentage | Percentage of classes attended |
| Average Exam Score | Student's average examination score |

All student records are fictional and created for educational purposes.

## Technologies Used
- **Programming Language:** C++
- **Development Environment:** Visual Studio Code
- **Data Format:** CSV (Comma-Separated Values)
- **Version Control:** GitHub

## Project Files
- `assign.cpp` — C++ source code used to generate and display the student dataset.
- `student_dataset.csv` — Generated CSV file containing 10 fictional student records.

## How to Run the Program

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure a C++ compiler is installed.
4. Compile the program using:

   `clang++ -std=c++11 assign.cpp -o assign`

5. Run the program on macOS or Linux using:

   `./assign`

6. The program displays the student dataset in a formatted table and generates `student_dataset.csv`.

## Expected Output

Upon successful execution, the program displays:

    Student dataset created successfully!
    Total Students: 10
    File saved as student_dataset.csv
